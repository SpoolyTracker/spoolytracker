# Guide d'Installation - Filament Manager Web (PC)

## Prérequis
*   **Node.js** : Doit déjà être installé.

## Lancement

1.  Ouvrez un terminal dans le dossier `apps/web`.
    *   Sur Windows : Shift + Clic Droit -> "Ouvrir PowerShell ici" dans le dossier `apps/web`.
2.  Installez les dépendances :
    ```bash
    npm install
    ```
3.  Lancez le site :
    ```bash
    npm run dev
    ```
4.  Ouvrez votre navigateur à l'adresse indiquée (généralement `http://localhost:5173`).

Vous devriez voir le tableau de bord des filaments sur votre ordinateur !
