# Contributing

Thanks for helping improve SpoolyTracker.

## Development

- Keep changes focused.
- Add or update tests when changing API behavior.
- Do not commit secrets, local databases, device configs, or generated build outputs.
- For self-host features, keep cloud behavior unchanged when `SELF_HOSTED` is not enabled.

## Pull Requests

Include:

- what changed;
- why it changed;
- how it was tested;
- screenshots for UI changes.
